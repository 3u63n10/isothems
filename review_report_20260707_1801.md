## Minor issues resolved during this verification
### 1. Supporting Information Empty Bibliography Crash
* **Problem:** The Supporting Information document (`SI_20260707_1801.tex`) contains no inline citations (`\cite`). When `bibtex` was executed on the SI, it generated an empty bibliography. Compiling this empty bibliography using `pdflatex` triggered an `Undefined control sequence` error in the `mciteplus` package during `\end{mcitethebibliography}`.
* **Impact:** Broken automated build/compilation loops on Windows systems.
* **Correction:** Added `\nocite{langmuir_adsorption_1918}` before `\bibliography{references}` in `SI_20260707_1801.tex` to force a non-empty bibliography.

### 2. Supporting Information $C_{1/2}$ Dimensional Mismatch
* **Problem:** The SI document in Section 2.10 defined the half-loading concentration $C_{1/2}$ as $C_{1/2} = \frac{1}{\exp(\varepsilon_{1/2}/RT) - 1}$. If $C_{\mathrm{ref}} \neq 1$, this leads to a unit mismatch because the numerator is dimensionless, while $C_{1/2}$ carries concentration units.
* **Correction:** Changed the equation to $C_{1/2} = \frac{C_{\mathrm{ref}}}{\exp(\varepsilon_{1/2}/RT) - 1}$ to ensure dimensional consistency with $C_{\mathrm{ref}}$.
